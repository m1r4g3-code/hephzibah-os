# Ramshaw Tracking Framework

Source: "The Ultimate Upwork Tracking Course" — Ryan Ramshaw, 2026-08-07
Free sheet: in the YouTube video description (https://www.youtube.com/watch?v=zWJPFivY5eU)

---

## The Three Tiers

### Tier 1 — Volume Metrics

Track the funnel. For boosting (inbound):

Views → Clicks → Invites/DMs → Booked Calls → Closes

For proposals (outbound):

Sent → Viewed → Replied → Booked Calls → Closes

### Tier 2 — Scale Metrics

| Metric | Formula |
|---|---|
| Revenue | Client payments (gross) |
| Commission to team | Cost of delivery |
| Profit | Revenue - Commission |
| Profit margin % | Profit / Revenue |
| Cost per click | Connects spend / Clicks |
| Cost per reply | Connects spend / Replies |
| Clicks to deal | Clicks / Total deals |
| CAC | Total connects spend / Total deals |
| AOV | Total revenue / Total clients |
| LTGP | (AOV × Profit margin %) - CAC |
| LTGP:CAC ratio | LTGP / CAC |

### Tier 3 — Northstar Metrics (only 2)

**1. Revenue per Connect**
= Total revenue / Total connects purchased (in dollar value)
Ryan's: $16.89 per $1 spent

**2. LTGP to CAC Ratio**
= LTGP / CAC
Ryan's: $15.89 (for every $1 acquiring a client, $15.89 profit)

## Proposal Benchmarks (for coaching students)

| Funnel Stage | Target Rate |
|---|---|
| Proposals → Viewed | 50% (gold standard, few hit this) |
| Viewed → Replied | 40% |
| Replied → Booked Call | 25% |
| Booked Call → Close | 30% |

Close rate >40% = you're charging too low. Raise prices.

---

## Diagnostic Logic

If view rate <30% → profile suppression issue. Fix profile first.
If reply rate <10% → proposal quality issue. Run /roast-proposal.
If close rate >40% → raise prices.
If LTGP:CAC <3x → acquisition is too expensive vs client value.
If revenue per connect <$5 → something is broken in the funnel.

## What Boosting Means

Ryan's model = inbound only via profile boosting (paying connects to show profile to active job posters). He stopped sending proposals because his profile ranks organically. This is the endgame, not the starting point. Requires: JSS >90%, multiple reviews, category ranking. Emmanuel is at the proposal stage now. Boosting becomes relevant after 3+ completed contracts.
