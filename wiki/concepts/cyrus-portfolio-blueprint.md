# Cyrus Osawaye Portfolio Blueprint

Source: https://cyrusosawaye.tech/

## What He Built

17 automation systems + 6 full-stack applications. Filtered by category (Automation and AI / Software). Each project has:
- Node count or lines of code
- Specific latency or throughput numbers
- Screenshots of actual workflow canvases
- Live demo or recorded walkthrough
- Upwork reviews embedded (social proof on-site)
- Code repository links

## The Positioning Line (steal this structure)

"Most automation people cannot build the application. Most developers do not do automation."

This one sentence does all the differentiation work. It names the gap, puts Cyrus in the middle, and explains why he charges premium rates without saying so directly.

Emmanuel's equivalent: "Most automation people don't do content. Most content people don't do automation. I do both."

Or: "I build the n8n workflow and the video it produces and the post that goes out. Most people hand off at step one."

## What Separates It From Generic Freelancer Portfolios

1. Specificity: "161-node workflow" not "complex automation." Numbers only the builder knows.
2. Error handling documented as a feature: "8 of 17 systems with explicit error handling." This signals production-grade thinking.
3. Latency transparency: admits where the model accounts for delay. Honest = trustworthy.
4. Hybrid positioning stated explicitly: not implied, named directly.
5. Ask Cirex chatbot: interactive AI agent built into the portfolio. Proof of capability as part of the presentation itself.
6. Upwork reviews embedded on-site: social proof that doesn't require leaving the page.

## What Emmanuel Needs To Build (Priority Order)

1. GitHub repos with real README files for each project. Links to code.
2. 6+ documented projects with: workflow canvas screenshot, one specific metric, one sentence on what breaks if done wrong.
3. The positioning line. State the hybrid gap explicitly.
4. Embed Upwork reviews once JSS builds.
5. "Ask [name]" chatbot eventually. Highest-impact trust signal.
